Theme: 35 Years of U.S.-Kazakhstan Partnership - Cultural Exchange, Innovation, and Shared Future.

🌟 About the Project
**Oyu.py** is a unique creative project that bridges cultural heritage with modern information technology. It connects the historic roots of Taraz and modern innovation through a blend of traditional Kazakh geometric patterns (*oyu-ornek*) and custom **Python code**. 

Instead of drawing patterns by hand, the intricate ethnic borders and geometric elements were entirely generated using mathematical algorithms and the Python `turtle` graphics library.

---

## 🚀 Features
* **Algorithmic Art:** Traditional ornament generation powered by custom Python scripts and trigonometry.
* **Interactive Web App:** A deployed Streamlit application allowing anyone to run the generation live.
* **Physical & Digital Fusion:** Features a printed code scroll and a museum-style QR code plate for exhibition visitors and judges to scan and explore instantly.

---

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Libraries:** `turtle`, `streamlit`, `Pillow`
* **Platform:** Streamlit Community Cloud & GitHub
